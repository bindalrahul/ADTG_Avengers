Use Case / Idea Title: Agentic Device Tree Generator (ADTG) An Agentic AI Platform for Embedded Hardware Bring-Up — Starting with Device Tree Generation
Problem Description: Board bring-up is one of the most knowledge-intensive tasks in embedded systems engineering. Engineers must manually correlate information across SoC Technical Reference Manuals (thousands of pages), silicon errata documents, Linux kernel Device Tree binding specifications, and board schematics — just to produce a Device Tree file that correctly describes the hardware to the Linux kernel. This manual cross-referencing accounts for significant bring-up effort and is largely information retrieval — not engineering judgement. ADTG replaces this with a fully agentic AI system.
Proposed Solution Overview: ADTG replaces the Device Tree generation with a fully agentic AI system.
Track:  AI in Industry - Semicon SW
Expected Business impact: Efficiency Gain
